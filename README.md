# MediBook 🏥

A modern doctor booking web application built with Next.js, Tailwind CSS, and reusable UI components.

## 🚀 Features
- 🔍 Find doctors by specialization
- 📅 Book appointments
- 🤖 AI-based recommendations
- ⭐ Patient testimonials
- 📱 Fully responsive UI

## 🛠 Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## 📦 Installation

```bash
npm install
npm run dev
